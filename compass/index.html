The orientation — reading value migration

My main angle is value migration: under rising returns to intelligence, profit leaves the activity that just got cheap and reappears where abundance hasn't reached. I built an instrument to read it firm by firm.

The AI Value Capture Simulation scores a company on Teece's logic — appropriability regime and complementary assets — against a modularity axis (how easily AI substitutes the components). Pick an industry, a firm, and a level of AI action, and read which moats hold and which dissipate.

Live tool · select Industry → Company → Scenario · the “Methodology & validation” tab carries the outcome test. If the embed is blank, open teece_tool.html directly (host it alongside this page).

Why the score isn't decorative

Across companies with real market-return data, a firm's Teece position tracks its risk-adjusted outcome — EV/Revenue explained at R² ≈ 0.63, with a positive, significant Fama-French-five-factor alpha relationship. This is early validation under the deliberate-confidence frame; the full pre-registered result resolves at Compass's November 2026 gate. One cycle can falsify; it cannot yet prove.

What's running today

The moat is the trajectory, not the method: a capable model can absorb an articulated method, but it cannot replay a path-dependent record run under uncertainty, on a clock. That thesis is implemented at the data-model level — here is the honest state of it.

Shipped — verifiable with code or access

  • Live multi-agent pipeline on Supabase / Postgres edge functions: RSS ingestion (4-hour cadence) → event processing (2-hour) → provenance-tracked hypothesis generation. Haiku for cheap extraction, Sonnet for reasoning.
  • Append-only, hash-chained record — the trajectory thesis enforced in the schema, not asserted in prose.
  • Prompt-injection fence on the extraction path, verified against a planted adversarial fixture with a committed test harness.
  • Source-agnostic merge contract: append-mostly upserts that coalesce null→value and never overwrite a fact with an inference.

Designed, not yet built — commitment tense

  • The human-disposal write path — schema present and audit-chained, interactive surface unbuilt.
  • Model-vendor abstraction and a portability suite — principle settled, build pending; vendor independence asserted, not yet verified.
  • Relationship-side ingestion — machinery live, real data still starved.
  • Constellation's full pre-registered validation — resolves at the November 2026 gate.
